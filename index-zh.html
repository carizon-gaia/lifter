01 / 项目概览研究思路

问题定义

从跨模态生成
到可渲染表示。

目标：以相机观测为条件，生成具备 LiDAR 几何与回波属性的场景表示。

逐场景重建通常依赖目标场景的真实 LiDAR 和场景级优化；直接生成点云或距离图则不天然具备连续场景表示。LiFTeR 的研究思路是在相机条件生成之后引入前馈高斯解码，将潜空间表征映射为可渲染的逐射线高斯，目标是减少逐场景优化并探索新场景与新位姿。

当前代码主要覆盖六相机条件扩散及 nuScenes 单帧 2DGS 渲染。更广的 LiDAR 条件输入、新位姿仿真和多帧能力属于研究目标或扩展分支，不能直接等同于当前主 CLI 已验证支持的功能。

02 / 生成方法

多视角 EDM 扩散

03 / 渲染方法

逐射线二维高斯泼溅

由潜变量预测高斯几何与传感器属性，经可微渲染得到距离、强度与回波丢失。

02 / 第一阶段

条件扩散与跨视角对齐

冻结编码器，训练多视角扩散 Transformer。

条件与网络

LiDAR 槽为待预测区域，六个相机槽提供条件。DiT 使用三维 RoPE、可学习视角嵌入与自注意力进行跨视角信息交互；默认主链不依赖显式相机到 LiDAR 的像素投影。

训练与采样

训练抽取不同噪声水平并预测干净潜变量；nuScenes 对真实 LiDAR 潜变量区域和结构填充分别归一化。推理从高斯噪声出发，使用 EDM/RES 迭代求解；默认 2ab、35 步，并在末尾执行最终去噪。

EDM 前向过程xσ = x0 + σ ε   ·   ε ∼ N(0, I)

模型根据噪声水平与相机条件预测 x0；实现还使用 EDM 预条件化和按噪声水平加权的损失。

DiT 使用 Cosmos Predict 预训练权重初始化后进行相机到 LiDAR 训练。推理主链的批次目前仍读取并编码 LiDAR video 以构造画布和评估数据；标准生成的 LiDAR 槽由噪声驱动，而非直接复制真实 LiDAR 潜变量。纯相机部署仍需适配数据接口。

03 / 第二阶段

高斯解码与 LiDAR 渲染

以下为 nuScenes V13 单帧 2DGS 路径。

潜变量 → 高斯属性

输入 [B, 16, 1, 8, 256]，经 2×2 分块转为 512 个标记；16 层主干混合双向 Mamba-2 与 Transformer，再上采样到 32×1024 光束网格。

光束 → 可观测回波

每条光束预测 12 个值：深度、4 个属性、2 个切向尺度、4 元数与不透明度。固定法向厚度适配 2DGS 接口；渲染后按回波丢失概率得到稀疏回波，并根据光束方向回投点云。

逐射线几何μ = oray + d · rray

高斯中心位于对应光束上；oray 是射线原点，rray 是单位方向，d 是预测距离。

训练默认冻结 DiT 与 VAE，只训练高斯头；无缓存时使用单步去噪潜变量，推理使用多步采样潜变量。监督包括距离、强度、回波丢失及几何项，真实回波掩码与邻域补值掩码需要区分。

技术问答

设计选择

为什么不只预测相机深度？

LiDAR 观测除了几何距离，还涉及强度、回波概率和按光束采样的稀疏返回。单独的相机深度预测并不自动提供这些传感器属性；不同方法也可能通过额外模块进行适配。

为什么使用 二维高斯？

方案将 2DGS 作为局部表面表达，并结合 GS-LiDAR 渲染逐光束结果。其效果依赖数据、参数化与对比设置，不能视作在所有任务上都优于 3DGS。

为什么在 潜空间进行高斯解码？

压缩后空间位置更少，有助于降低序列长度和计算、显存需求；但生成质量与效率仍需结合实际模型、硬件及实验验证。

为什么使用相机作为条件，而不是 占据表示？

相机观测更常见、更易获取。该选择不意味着占据表示无效；不同条件输入具有不同的数据、几何和部署要求。

为什么生成高斯场，而不是只生成距离图？

距离图可以直接由 LiDAR VAE 解码；高斯场则可作为可渲染的场景表示，在不同位姿重复渲染，而无需在每个仿真时刻重新运行扩散模型。多场景对比进一步评估了新视角表现，但新显露区域的覆盖情况尚未单独量化。论文表 1 使用 VAE 解码评估生成，表 2、3 使用高斯解码评估重建；在同帧对照中，高斯解码的深度 PSNR 为 17.2053 dB，VAE 为 17.0658 dB，但高斯解码并非所有指标都更好。

为什么将高斯位置约束在激光射线上？

射线方向由传感器配置确定，模型只需预测沿射线的深度。在保持其他设置不变、改为自由预测三维位置并重新训练的消融实验中，Chamfer 距离从 1.5955 增至 14.4976，深度 PSNR 从 17.2053 dB 降至 13.1531 dB。这是该实验设置下的消融结果，不能直接推广到所有模型和数据。

与逐场景重建方法的输入条件相同吗？

并不完全相同。同帧评估中，LiFTeR 使用测试时刻的六路相机图像；测试场景未用于 DiT 和高斯解码器的训练。逐场景方法则使用其他帧的真实 LiDAR 进行场景优化。因此应结合输入模态、可用数据与任务设置理解比较结果，不能把它视为完全同条件的对照。

新视角和多帧仿真如何处理动态物体？

仿真应用使用 nuScenes 三维标注将预测高斯拆分为静态与动态部分；动态高斯在规范坐标系下跨帧聚合，再与静态场景一起渲染。表 3 的中间查询帧使用相邻两帧。摆脱标注依赖仍是未来工作，这些研究结果也不等同于当前单帧主 CLI 已验证的能力。
